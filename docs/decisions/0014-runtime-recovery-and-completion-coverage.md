# ADR-0014 运行恢复、pod 临界区与验收全集

> 状态：`accepted`
> 提出日期：2026-10-02
> 裁决日期：2026-10-02
> 基线提交：`d8fafff3`
> 相关：ADR-0005、ADR-0010、ADR-0011、ADR-0012、ADR-0013；[深审与修复设计](../reviews/2026-10-02-reliability-and-contract-repair-design.md)

## 背景

gate-log §13.140 用真实进程和公开工具复现了候选恢复不可达、死锁残留、取消后写入、同 pod 双认领和漏验收归档。用户在审阅设计与结果后确认继续实施。本记录固定前四批正确性修复的边界；后续发布渠道、宿主可信身份与退出能力不能据此宣称已实现。

## 决定

### 1. 取消是执行上下文，不是请求载荷

MCP SDK v2 的 `ctx.mcpReq.signal` 经两宿主组合根进入已有领域执行选项。提交前中止等待和新副作用；提交后继续必要结算，取消可重建投影不否定已提交结果。SIGINT、SIGTERM、SIGHUP 均关闭 transport 并传达在途取消。进程不可捕获退出仍依赖文件恢复。

### 2. 恢复保留健康准入，借现有 reconcile 暴露入口

status、verify、维护 preview 始终零写。已发布 Demand 的候选残留由独立只读观察识别，`reconcile` 返回有摘要的 `WakeflowDemandRuntimeRecoveryPlan`；apply 在写入前复验。成功后重新预览普通维护，再按原幂等键重试业务请求。

恢复只调用已有候选结算规则：未提交候选退役，已经链接的提交结算后解除候选链接，原事件字节不变。活动或未知 owner、未知文件、资源漂移均不被自动清理。维护恢复者复用既有 Demand 发布锁相互协调；同进程恢复与 append 共用队列。跨进程正常 append 保留 no-replace 槽位、owner 证明及精确节点操作，不新增事件流锁或业务状态机。不能把“其他 writer 不持恢复锁”误写成可以忽略 owner 和 CAS 检查。

board 和 projection 的 owner 在正常写入口退役已证明失活的锁；Foundation 本身继续不自动偷锁。调用者必须声明相关暂存目标，不能清理未知节点。

### 3. pod 的占用变化共用短临界区

公开 create、continue、终态完成/取消及 pod 关闭使用按 podId 隔离的运行锁。在锁内复验配置和当前占用；关闭重新推导计划。锁放在私有 runtime 中，不进入事件或归档。

进程死亡不代表事务结束。未结的 Demand 发布意图与生命周期日志继续保留对应 pod 的占用，直到原操作恢复；不能只扫描 claimed 看板项。不同 pod 保持独立，配置 CAS 继续防止覆盖他人的配置变更。宿主效果及 Agent 等待不进入该临界区。

### 4. 新包发布和完成使用同一验收语法

requirement、bug、supplement 新发布前必须有非空、可引用的顶层验收列表；段落或表格不能假装成列表项。确认摘要包含验收节。research 保持独立的文档完成语义。

完成时按不可变需求的标准全集核验：controller-only 由已接受实现锚点覆盖；real-environment 由当前代际已接受测试合同覆盖，不能用实现锚点与部分测试的并集代替全量测试。只规划、被替代或历史测试代际不计为当前满足。缺项默认阻断，没有隐式豁免。取消允许工作尚未完成，但仍须满足原有权威和归档完整性要求。

这落实 Q6 与 Q8 的推荐默认值。新标准仍不能原地写入冻结 authority；continue 沿用原标准。补充需求的机器追溯等后续合同另行实施，不能以文案承诺尚不存在的退出通道。

### 5. 历史完整性优先

不改已有事件、reducer 状态形状或历史摘要。v1 Ledger 的章节读取合同保持；收紧的是新发布准入和未来完成门。旧完成/取消归档仍按其原始封存证据读取。今后若要改变状态模型语义，保留版本化验证与显式迁移，不以移除摘要校验实现兼容；这落实 Q3 的推荐路线。

## 后果与验证

修改入口、所属能力和治理模块，更新发布摘要上限与生成 Schema、所属 skills，重建两宿主制品。将真实协议取消、关闭信号、SIGKILL 候选残留、死锁、pod 交错、缺少验收及完整验收的正负用例纳入持续测试。小批次先 focused，再执行完整 `npm test`、双宿主 smoke 和差异检查。

八批路线仍分批推进。版本 bump、提交、tag、发布、安装缓存刷新与不可逆外部操作维持各自授权边界。本记录不把全部 open-items 标记为完成。
