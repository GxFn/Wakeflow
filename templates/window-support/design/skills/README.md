# Design Skills

These optional local skills help Design windows shape requirements and review
experience quality before Wakeflow controller intake. They do not replace the
workspace AGENTS rules, user decisions, or controller acceptance.

Use a skill only when it fits the current Design question:

- `requirements-framing/SKILL.md`: turn vague requests into a Wakeflow-ready
  original plan or requirement design boundary.
- `design-interview-grill/SKILL.md`: challenge a proposed requirement with
  focused questions before it becomes executable scope.
- `vertical-slice-requirement-planning/SKILL.md`: break a confirmed demand
  into user-value slices, producer/consumer order, and evidence boundaries.
- `heuristic-design-review/SKILL.md`: review a user flow against established
  usability heuristics.
- `accessibility-design-review/SKILL.md`: prepare accessibility requirements
  and design risks before implementation or testing.
- `handoff-quality-gate/SKILL.md`: check whether a Design output is ready to
  hand to the Wakeflow controller.

Keep source-specific rules with the owning product repository. Keep hard
Wakeflow boundaries in AGENTS.md.
