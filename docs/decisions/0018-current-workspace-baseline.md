# ADR-0018 当前工作区结构作为首个支持基线

> 状态：`accepted`
> 日期：2026-10-02
> 来源：用户要求新建测试环境，不再考虑既有 Wakeflow 本地文件与结构的升级，按当前最新实现作为首版本。
> 相关：ADR-0017 的并发与证据决定保留；其旧工作区迁移与兼容启用方案由本文取代。

## 决定

1. 当前工作区结构是唯一支持的基线。新验证使用新建的一次性工作区；已有开发版工作区保留为历史材料，不修改、转换、自动清理或复用其绑定。
2. 不提供旧配置读取器、跨格式转换、v1→v2 升级动作或停写确认参数。未知格式按现有严格输入边界拒绝，不自动更改版本头，也不以重新初始化覆盖已有权威。
3. 保留同一基线内的正常 `reconfigure`、`reconcile` 和中断 `recover`，以及共享/独占作用域、进程实例所有权、投影来源重读和证据主体分离。故障恢复不等于格式迁移。
4. 插件候选版本按用户要求使用小版本 `1.1.0-rc.1`。当前配置、锁、status/verify 的协议编号保持现有标识 `2`；编号用于严格识别当前合同，不代表插件大版本，也不承诺旧格式兼容。
5. 安装构建仍使用独立版本目录，不覆盖运行中构建。部署完整性与本地数据迁移是不同问题；不提供迁移不意味着可以在同一版本路径混用不同字节。

## 实施

移除本轮新增的双版本配置 Schema、升级 blocker/确认字段、旧 intent 特例和锁 v1 解析分支。调整所有真实消费者、生成合同、技能和测试；保留当前格式配置变更中断后的写入隔离与公开恢复回归。旧跨构建实验是历史证据，不再作为当前支持范围。

现有测试区尚未执行原地升级；此前操作方的停写确认随该升级计划取消。新测试区不继承旧目录或记录。此前已存在的业务合同与恢复路径不因本决定做无关重写，也不据此宣称未来所有构建之间具有持久格式兼容性。
