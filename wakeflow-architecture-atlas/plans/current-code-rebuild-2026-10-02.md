## 验证计划

1. 检查器回归、阅读器类型、全部来源与符号、导入边和测试锚点。
2. 本地浏览器真实解析与渲染每张 Mermaid，保存渲染回执；抽查各图默认阅读比例与密度。
3. 图谱独立 `npm run check` 与根 `git diff --check`。
4. 执行根验证门作为证据；若既有未提交实现使其失败，准确记录失败，不修改产品来让图谱通过。
5. FigJam 分区、节点、连线与本地图逐项对照，并截图检查。真实宿主测试不由静态检查或一次性场景替代。

## 初始发现

旧图谱以 2026-09-18 为基线。51 份文档、72 个 Mermaid 块中，49 份来源指纹漂移；旧配置路径、部分导入边及阶段文字已失效。隔离检查器只识别 `.build/`，而仓库使用等价的根锚定 `/.build/`，需要在图谱检查器中正确识别并加回归覆盖。
